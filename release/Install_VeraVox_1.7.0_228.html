VeraVox 1.7.0

A queue that clears itself as you listen, the Playback Mode from your phone, a Mac that stays awake while you use the Web Remote, and a much faster Dynamic Range analysis that explains its figures. Your library, queues, saved playlists and settings carry over.

The queue

  • Remove Played Tracks, in Settings ▸ Playback, takes each track out of the queue once you have heard it to the end or left it with Next, so a long queue, shuffled or not, shows only what is left, after a restart too. While it is on, Repeat offers Repeat One but not Repeat Queue, Previous starts the track again, and a queue opened from a saved playlist lets go of it, so the playlist keeps all its tracks. It is off unless you turn it on.

Web Remote and Playback Mode

  • Choose your DAC's Playback Mode, Exclusive or Shared Output, in the Web Remote's Settings, with Reset preference. When a Play from the phone needs an answer first, for a DAC not yet set up or a multichannel file your device can't carry in full, the question appears on the phone, in the same words as on the Mac.
  • Like the output, the Playback Mode now changes only while playback is stopped, everywhere, Settings ▸ Output included. With a network renderer as the output, VeraVox no longer asks about a local DAC that won't play.
  • While the Web Remote is open on your phone, your Mac stays awake, even on battery, so the connection holds. A few minutes after the phone locks or the Web Remote closes, the Mac returns to its own energy settings.

Dynamic Range

  • Analysing a large library is several times faster: VeraVox reads several files at once, as many as your Mac has performance cores (one on battery), or the number you choose under Files at once in Settings ▸ Library ▸ Dynamic Range. While music plays it goes one file at a time, so playback comes first. A Mac left on overnight no longer slows it down, and on mains power it no longer sleeps halfway. From a NAS, DSD files no longer need gigabytes of memory.
  • One sheet handles the analysis and the reports, the same from Tools, Settings, a folder's row, an album or Track Info, and says what it will do before it starts. Tools ▸ Export Library Dynamic Range Reports… exports the reports of the whole library, into each album's folder or one you choose. A run can be stopped from the Tools menu.
  • A multichannel track can read DR1, or another very low figure, when one channel, usually a height channel of an immersive mix, holds its sound in a single three-second block. The figure stays the one every meter gives, but now carries a †, and the album report, Track Info and the player say which channels, and what the track and the album would read without them. Albums analysed before show this once you analyse them again: right-click the album and choose Analyze Dynamic Range.
  • Reports exported into one folder now have a name per album, the same at every export. Reports already there under the earlier names stay beside the new ones, so start from an empty folder for a clean set. The text log lists the album and its format line by line, as classic DR logs do, and the log and the PDF give the channel count, such as 7.1.4 (12 channels).

Channels and formats

  • A file's channels have one name throughout the app: 5.1 where space is short, 5.1 (6 channels) where there is room. An album's Get Info names each DSD rate, such as 2822.4 kHz (DSD64).

Other fixes

  • When macOS reconnects a network share at a different location, the library, the queue, saved playlists and play history follow it. Tracks that an earlier reconnection left in the library twice become one again at the first launch, with their ratings, favourites and Dynamic Range.
  • Saving a library backup over an earlier one works as expected, and a backup or restore that can't complete says why in plain words.
  • The Surround Scope draws every multichannel layout the way it plays.

Almost every change in this update began with a message from someone who uses VeraVox: thank you for writing in.
