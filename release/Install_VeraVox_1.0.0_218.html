VeraVox 1.0.0

This is the released version of the app you have been testing. Nothing in the playback path has changed since the last beta: same engine, same formats, same signal path.

What changes for you

  • The beta period is over. On first launch VeraVox offers a 30-day free trial, with no card and no account, or you can enter a licence key you already have.
  • Your library, queues, saved playlists and settings are untouched. This is an ordinary update, not a reinstall.

New since the last beta

  • New in Settings: if you own a Tuneshine™ LED display, VeraVox can show the cover art of what is playing on it. It sends the artwork embedded in your own files, so a self-made rip shows its real cover. Off by default, and everything stays on your local network.
  • Search understands more of what you type: a minus in front of a word excludes it, and punctuation inside a title or a name no longer breaks the query.
  • The Smart Playlists and saved playlists lists can be filtered by name, in the app and in the Web Remote, and smart playlists gained a "does not contain" rule for text fields.
  • The instrument windows look different: the panels and the booklet reader now take the same window material, corners and border as every other window in the app.
  • The scanning indicator now belongs to the scan that is really running: it no longer vanishes part way through a rebuild, and it no longer flickers when a background check finds nothing to do.
  • The diagnostic report is readable again. A single repeated line about network devices was most of its length, and each device is now reported once.

Thank you. Several of these exist because you took the time to describe what you saw.
